1. EM Algorithm with a Suitable Example [5 Marks]

Definition: The Expectation–Maximization (EM) algorithm is an iterative method used to find Maximum Likelihood estimates of parameters in models that contain hidden (latent) variables or missing data.

Steps of EM Algorithm
  • Initialization: Assign random initial values to the model parameters θ.
  • E-Step (Expectation): Using current parameters, compute the expected value of the hidden variables, i.e. the posterior probability P(Z | X, θold).
  • M-Step (Maximization): Re-estimate the parameters θ so that the expected log-likelihood computed in the E-step is maximized.
  • Repeat: E-step and M-step are repeated until the log-likelihood converges (no significant change).
Example: Two Coins Problem

Two biased coins A and B with unknown head probabilities θA and θB. A coin is picked randomly (we do not know which) and tossed 10 times; this is repeated 5 times. Only the number of heads is recorded — the identity of the coin is the hidden variable.

  • E-Step: For each set of tosses, compute the probability that it came from coin A or coin B using the current θ values.
  • M-Step: Update θA and θB as the weighted average of heads, using those probabilities as weights.
  • After a few iterations the estimates converge close to the true values.
Applications

Gaussian Mixture Models, Hidden Markov Models (Baum–Welch), missing-data imputation, and clustering.

2. Factor Analysis and its Role in Dimensionality Reduction [5 Marks]

Definition: Factor Analysis (FA) is a statistical latent-variable technique which explains the correlations among a large set of observed variables using a small number of unobserved variables called factors.

Model
x = Λ z + μ + ε
  • x – observed d-dimensional data vector.
  • z – latent factor vector of dimension k (k << d), z ~ N(0, I).
  • Λ – factor loading matrix showing how much each factor influences each variable.
  • μ – mean vector, ε – noise, ε ~ N(0, Ψ) with diagonal Ψ (unique variance of each variable).
Role in Dimensionality Reduction
  • Represents d observed features using only k factors, so storage and computation are reduced.
  • Removes redundancy by grouping highly correlated variables into one factor.
  • Separates common variance (shared, useful information) from noise/unique variance, so the reduced data is cleaner.
  • Gives interpretable factors (e.g. marks in Physics, Chemistry, Maths reduce to a single factor "Science Ability").
  • Helps in visualization and avoids the curse of dimensionality, improving model accuracy.

3. Relationship between Hidden States and Observations in an HMM [5 Marks]

A Hidden Markov Model is a doubly stochastic process. The underlying process is a Markov chain of hidden states (q1…qT) which cannot be observed directly. Each hidden state emits a visible observation (o1…oT), and only these observations are available to us.

Relationship
  • States are hidden, observations are visible: the state must be inferred from the observation sequence.
  • Transition probability A: aij = P(qt=Sj | qt-1=Si) — links one hidden state to the next (first-order Markov assumption).
  • Emission probability B: bj(ot) = P(ot | qt=Sj) — this is the direct link between a hidden state and its observation.
  • Output independence: the current observation depends only on the current state, not on previous states or observations.
Joint Probability
P(O, Q) = πq1 ∏t=2..T aq(t-1)q(t) ∏t=1..T bq(t)(ot)
Example

Hidden states = {Rainy, Sunny}; Observations = {Umbrella, No Umbrella}. We cannot see the weather, but from whether a person carries an umbrella we infer the weather. Decoding the most likely hidden state sequence is done by the Viterbi algorithm.

4. Conditional Random Fields (CRF) [5 Marks]

Definition: A Conditional Random Field is a discriminative, undirected probabilistic graphical model used for structured prediction (sequence labelling). It directly models the conditional distribution P(Y | X) of the label sequence Y given the observation sequence X.

Linear-Chain CRF Formula
P(y | x) = (1 / Z(x)) · exp( Σt Σk λk fk(yt-1, yt, x, t) )
  • fk – feature functions defined on labels and the input.
  • λk – weights learned from training data.
  • Z(x) – partition function used for normalization.
Key Points
  • Since it is conditional, it can use rich, overlapping features of the whole input without modelling P(X).
  • Global normalization avoids the label-bias problem of MEMMs.
  • Training uses maximum conditional log-likelihood with gradient methods; inference uses Viterbi / forward–backward.
Applications

Part-of-Speech tagging, Named Entity Recognition, shallow parsing, gene prediction in bioinformatics, and image segmentation.

5. Mixtures of Gaussians and their Use in Probabilistic Clustering [10 Marks]

Definition: A Gaussian Mixture Model (GMM) is a probabilistic model which assumes that the data is generated from a weighted combination of a finite number of Gaussian distributions with unknown parameters. Each Gaussian component represents one cluster.

Mathematical Model
p(x) = Σk=1..K πk N(x | μk, Σk)
  • K – number of Gaussian components (clusters).
  • πk – mixing coefficient, 0 ≤ πk ≤ 1 and Σ πk = 1.
  • μk – mean vector, Σk – covariance matrix of component k.
  • A hidden variable z indicates which component generated a data point.
Parameter Estimation using EM
  • Initialization: choose initial πk, μk, Σk (often from k-means).
  • E-Step: compute the responsibility of component k for point xn:
    γ(znk) = πk N(xn|μk,Σk) / Σj πj N(xn|μj,Σj)
  • M-Step: update parameters using these responsibilities — Nk = Σn γ(znk), μk = (1/Nk) Σn γ(znk) xn, Σk = (1/Nk) Σn γ(znk)(xn-μk)(xn-μk)T, πk = Nk / N.
  • Repeat until the log-likelihood converges.
Use in Probabilistic (Soft) Clustering
  • Instead of assigning a point to exactly one cluster, GMM gives the probability of membership in every cluster — this is called soft clustering.
  • A point can be, for example, 70% in cluster 1 and 30% in cluster 2, which is useful when clusters overlap.
  • The final hard label (if needed) is the cluster with the highest responsibility.
  • Because each component has its own covariance matrix, clusters can be elliptical, of different size, shape and orientation, unlike k-means which assumes spherical clusters.
  • Model selection (choosing K) is done using AIC / BIC or cross-validation.
Advantages
  • Soft, probabilistic assignment with a proper statistical foundation.
  • Handles overlapping and non-spherical clusters; can be used for density estimation, anomaly detection and data generation.
Limitations
  • Number of clusters K must be specified in advance.
  • Sensitive to initialization; EM may converge to a local optimum.
  • Computationally costlier than k-means; singular covariance problem may occur.
Applications

Speaker recognition, image segmentation, customer segmentation, background subtraction in videos, and anomaly detection.

6. Undirected Graphical Model - Components and Uses [10 Marks]

Definition: An Undirected Graphical Model, also called a Markov Random Field (MRF) or Markov Network, is a probabilistic model in which random variables are represented as nodes of an undirected graph and the edges represent mutual (symmetric) dependency rather than cause–effect direction.

Main Components
  • Nodes (Vertices): each node represents one random variable, which may be observed or hidden.
  • Undirected Edges: an edge between two nodes means the two variables are directly dependent on each other; absence of an edge implies conditional independence.
  • Cliques: a clique is a subset of nodes in which every pair of nodes is connected. A maximal clique cannot be extended by adding another node. The joint distribution is factorized over maximal cliques.
  • Potential Functions (Factors) ψC: a non-negative function defined on each clique C which measures how compatible the variable values in that clique are. Unlike CPTs in Bayesian networks, these are not probabilities.
  • Partition Function Z: the normalization constant that makes the total probability equal to 1.
Joint Distribution
P(X) = (1/Z) ∏C ∈ cliques ψC(XC) ,   Z = ΣX ∏C ψC(XC)

Writing ψC = exp(-E(XC)) gives the Gibbs / Boltzmann distribution, where E is an energy function; lower energy means higher probability.

Conditional Independence (Markov Properties)
  • Pairwise: two non-adjacent nodes are independent given all other nodes.
  • Local (Markov blanket): a node is independent of all other nodes given its immediate neighbours.
  • Global: sets A and B are independent given S if every path from A to B passes through S (graph separation).
  • Hammersley–Clifford theorem: for strictly positive distributions, the Markov properties and clique factorization are equivalent.
Common Types
  • Ising / Potts model – used in physics and image modelling.
  • Boltzmann Machine and Restricted Boltzmann Machine (RBM) – energy based learning models.
  • Conditional Random Fields (CRF) – discriminative undirected model for sequence labelling.
Uses / Applications
  • Computer vision: image denoising, image segmentation, stereo matching and texture modelling, where neighbouring pixels influence each other symmetrically.
  • Natural Language Processing: POS tagging, NER and information extraction using CRFs.
  • Social network analysis and relational data, where relationships have no natural direction.
  • Bioinformatics: protein structure prediction and gene interaction networks.
  • Recommendation and deep learning: RBMs for collaborative filtering and pre-training.
Advantages and Limitations
  • Advantages: naturally models symmetric/cyclic relationships; simple conditional independence test using separation; flexible potential functions.
  • Limitations: computing the partition function Z is intractable for large graphs, so approximate inference (Gibbs sampling, loopy belief propagation, variational methods) is required; parameters are less interpretable than in Bayesian networks.
